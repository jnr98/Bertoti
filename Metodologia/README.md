## Meus Projetos

### Em 2026-1

### Empresa Parceira: [IPEM - Instituto de Pesos e Medidas](https://github.com/LizardsDBA/API-2026-3)

### Problema:
O desafio consistiu no desenvolvimento de um sistema web para controle e análise dos abastecimentos das viaturas do IPEM – Regional de São José dos Campos, substituindo o processo manual realizado através de pranchetas físicas mantidas nos veículos. Os técnicos registravam manualmente informações dificultando a consolidação mensal dos dados, comparação entre viaturas e o acompanhamento do consumo médio de combustível.

### Solução Entregue pela Equipe:
**FlowTrack** — Plataforma de Controle de Abastecimento e Utilização de Viaturas, desenvolvido para digitalizar e centralizar o gerenciamento das informações da frota. A plataforma possibilita o registro de abastecimentos, histórico de quilometragem, alertas de manutenção preventiva baseados em quilometragem e o acompanhamento de técnicos e veículos através de mapas e indicadores interativos.

[Repositório do Projeto](https://github.com/LizardsDBA/API-2026-3)

#### Tecnologias Utilizadas
> - **Java**: Utilizado no desenvolvimento do backend, estruturando toda a regra de negócio do projeto.
> - **Spring Boot**: Framework base para a construção das APIs REST da aplicação.
> - **MySQL**: Banco de dados relacional utilizado para armazenar os registros das viaturas, técnicos e abastecimentos.
> - **HTML, CSS e JavaScript**: Utilizados para o desenvolvimento da interface gráfica e consumo das APIs.
> - **Git e GitHub**: Essenciais para o controle de versão e desenvolvimento colaborativo.
> - **Jira**: Ferramenta utilizada para o gerenciamento de tarefas e acompanhamento das Sprints.
